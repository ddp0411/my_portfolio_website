## Overview

A lightweight natural-language-processing utility that automatically identifies
the language a piece of text is written in and, when needed, translates it into
a chosen target language.

## Problem

Multilingual applications constantly receive text in an unknown language.
Before you can translate, moderate, or route that text, you first have to know
what language it is — reliably and without asking the user.

## Approach

- Detects the source language of the input with the **`langdetect`** library
- Wraps the whole flow in a single `detect_and_translate(text, target_language)`
  function
- Short-circuits when the detected language already matches the target — the
  text is returned unchanged, avoiding a wasted translation call
- Otherwise translates from the detected language into the target (for example,
  English → Swahili) using a Google Translate wrapper

## Tech stack

Python · langdetect · googletrans
